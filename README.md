# Predicting-Wind-Speed-with-LSTM
A PyTorch-based Deep Learning pipeline for regional weather nowcasting using multi-variable time-series data and a dual-layer LSTM network. Features automated preprocessing, sliding window sequence generation, and predictive wind speed modeling.
